# Repl20Code

Julietta Alaverdian's VB6 Replicator123 (`Repl123.exe`) that replicates file(s) to a number of hosts, with ping and file-state helpers (`vbping`, `FileState`). Open `Replicator123.vbp` in the VB6 IDE.

**Source last updated:** 2026-08-27 · **Language:** VB6 · **Target:** VB6 Win32 · **Output:** WinForms exe

## Solution structure

| Project | Language | Type | Purpose |
|---------|----------|------|---------|
| `Replicator` (`Replicator123.vbp`) | VB6 | WinForms exe | Replicates file(s) to a number of hosts. |

## How to open

Open the `.vbp` in Visual Basic 6.0 IDE:
- `Replicator123.vbp`

## Requirements

- Visual Basic 6.0 IDE
- Registered OCX/DLL dependencies referenced by the `.vbp` (may need to be installed separately):
  - `MSCOMCTL.OCX`
  - `comdlg32.ocx`
